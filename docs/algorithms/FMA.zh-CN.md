# 融合乘加的实现

下文源码与测试路径均相对于 `src/bootstrap-c99/complex/`。提及的测试日志由对应套件生成，不是必需的源码输入。

fma.c 使用整数运算实现 binary32 和 binary64（也包括 Windows long double）的融合乘加，不依赖 FMA 指令，也不改变舍入模式。

有限输入被解码为带符号整数有效数乘以二的幂。精确乘积使用四个以 2^32 为基数的分段表示。乘积与加数放到同一离散格点上：binary32 的最小单位为 2^-298，binary64 为 2^-2148。在舍弃任何位之前完成带符号加减。乘积的最大位索引分别为 553 和 4195；20 或 136 个有效分段分别提供 640 或 4352 位，包含进位余量。乘法累加器的最大值不超过 (2^32-1)^2+2*(2^32-1)=2^64-1。

最终结果保留目标精度或次正规数的最小单位，再使用保护位和粘滞位进行最近偶数或定向舍入。溢出按无限指数范围下的舍入结果判定。下溢采用舍入后微小性判定，并要求结果不精确。精确抵消仅在向下舍入时产生负零；同号输入零保留符号。

非有限值处理会将信号 NaN 转为安静 NaN 并触发无效操作异常，保留首个 NaN 的载荷，拒绝零乘无穷和相反符号的无穷项相加，其余情况传播无穷。本实现选择在零乘无穷时触发无效操作异常，即使加数是安静 NaN。定义域错误使用 EDOM；溢出及不精确的微小结果使用 ERANGE。不需要报告新错误时，已有异常标志和 errno 保持不变。

make-fma-reference.ps1 只生成 C 测试源码。它使用独立的带符号 BigInteger 求和与 DivRem 舍入，在四种模式下提供 480 组三元输入，覆盖次正规输入和极端指数差；不创建或修改编译器二进制产物。两代自制编译器分别编译并链接这些测试数据。专项测试还覆盖精确乘积抵消、溢出抵消、次正规/正规边界的中点、带符号零、NaN、无穷，以及已有异常标志和 errno 的保留。

算法测试补充发布构建与审计，不构成完整 C89/C99 符合性证明。

# 实现设计说明

本页介绍阅读源码时需要了解的内部设计。下文源码路径均相对于 `src/bootstrap-c99/`。

## 初始化解析状态

编译器在解析嵌套初始化时保存并恢复状态。检查点帧共 58 个槽位：声明及指定初始化相关标志使用 54/55，宽字面量和拼接字符串标志独立使用 56/57。分配、保存、恢复必须使用同一布局，避免内层解析破坏外层状态。

相关测试调用实际编译器的检查点函数，覆盖嵌套帧和外层标志组合；聚合初始化回归仍由完整测试套件执行。此处记录的是内部布局，使用者不应依赖这些槽位作为公开接口。

## 公共头文件与运行库

`include/` 提供公共头文件；C89 模式的运行库通过 `runtime/runtime-c89.c` 选择数学、数值转换及 locale 布局策略。编译器的 `C1_RUNTIME=c89` 仅用于目标文件模式下的运行库导出策略，普通应用应清空它。

公共函数原型使用实现保留的形参名，避免调用者宏意外改写声明。stdio 的 FILE/fpos_t 成员以及 C89 locale 的额外 lconv 成员也采用对应保留名称；运行库编译使用相同映射，保持布局一致。C99 locale 头文件保留其标准成员名。

`namespace/` 测试公共头文件、运行库符号、宏名碰撞与语言模式约定。基础自举阶段的源码内联测试具有自己的头文件配置，不能单独代替公共接口测试。

## 自举与完整数学运行库

最终编译器第零代使用 `runtime/bootstrap-runtime.c`。随后两代使用完整 `runtime/runtime.c`，包含复数、泛型数学以及相应实数数学接口；C89 运行库排除仅属于 C99 的新增接口。完整构建依赖关系见 [BOOTSTRAP.zh-CN.md](../BOOTSTRAP.zh-CN.md)。

`complex/SUITES.json` 列出数学与复数测试套件及完成标志。数学测试可以使用 PowerShell 生成 C 参考数据文本，但这些 C 文件对应的二进制仍由自制编译器和链接器生成。各算法的计算方法、独立参考算法及数值边界见本目录的 [算法说明](README.zh-CN.md)。

## 如何定位验证

语言规则与模式差异主要由 `diagnostics/`、`namespace/` 和 `features/` 测试；基础功能回归位于 `base/tests/`。独立审计检查诊断、非法输入的拒绝结果、实际执行结果及两代产物一致性。部分数学夹具包含由自制编译器生成的 x64 MXCSR 操作代码，用于测试四种舍入模式。

测试计数及构建结果以实际运行日志为准。特定用例通过不等于所有输入正确，也不扩大项目的 C99 或可选浮点附录支持声明。

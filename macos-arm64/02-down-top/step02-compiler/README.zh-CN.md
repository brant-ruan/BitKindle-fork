# 阶段 2：原生 ARM64 C1 递归下降编译器后端 (Step 02 - Compiler)

## 概述

拥有了阶段 1 的 Mach-O 链接器后，我们进入**编译器**阶段。

`c1-arm64` 实现了原版 C1 语言子集向 ARM64 (AArch64) 原生指令的翻译，涵盖词法扫描、递归下降语法分析、AAPCS64 栈帧管理、虚拟寄存器分配以及机器指令二进制发射，并输出通用的 `.c1o` 目标文件。

---

## 文件结构

- `src/c1_arm64.c`: 编译器完整源码实现（单文件自包含设计）；
- `tests/test_calc.c`: 涵盖算术运算、循环递增、多参数函数调用与条件跳转的测试程序；
- `build_and_test.sh`: 编译器一键构建、源码编译、目标文件链接与退出码验证脚本。

---

## 核心技术突破

1. **AAPCS64 寄存器约定与栈帧设计**：
   - 使用 `stp x29, x30, [sp, #-16]!` 与 `mov x29, sp` 维护调用栈；
   - 函数入参通过 `x0` ~ `x7` 依次传递；
   - 本地局部变量在栈上按 16 字节对齐分配空间；
   - 表达式求值统一以 `x0` 作为主累加寄存器。
2. **条件跳转与立即数反转编码**：
   - ARM64 的 `cset Rd, cond` 指令底层实际上是 `csinc Rd, zr, zr, invert(cond)`；
   - 生成比较指令时，准确处理条件码的反转（如 `<` 与 `>=`），避免逻辑颠倒。
3. **C 语法子集支持**：
   - 数据类型：`int`、`char` 以及多级指针声明（如 `char **argv`）；
   - 控制流：`if` / `else` 分支、`while` 循环、`return` 语句；
   - 表达式：二元运算（`+`, `-`, `*`, `/`, `%`）、逻辑与关系比较（`==`, `!=`, `<`, `<=`, `>`, `>=`）、函数调用。

# 翻译资源和派生声明器上限

本表依据 `bootstrap-c99/host/compiler.c` 与 `host/object-output.c` 中的容量检查，说明编译器的翻译资源限制。它记录实现边界，不表示所有容量能在同一程序中同时用尽，也不替代标准最低能力测试。内部预置符号、生成代码、对齐和临时变量均可能占用共享预算。

| 资源 | 上限或拒绝条件 | 源码入口 |
| --- | --- | --- |
| 标识符 | 2048 个内部条目（含预置名字）；前 63 个解码后字符显著，区分大小写，规范化 UTF-8 拼写存入每项 256 字节槽 | intern |
| 普通纯指针链 | 最多 15 层；再派生一层被拒绝 | make_pointer |
| 声明器 | 递归超过 64 层拒绝；单次构造链最多 255 个节点 | declarator、decl_node |
| 数组类型 | 共用 1024 个条目；固定类型按基类型/长度复用，运行时类型还记录捕获的长度和大小位置 | make_array、rebase_array |
| 固定数组大小 | 常量长度为正且不超过 `0x1a00000`；固定元素大小与长度的乘积也不能超过该字节上限 | runtime_array_bound、make_array |
| 函数类型 | 1024 个不同签名 | make_function |
| 函数参数 | 最多 127 个具名/固定参数；变参尾部另按编码处理 | parameter、function_suffix |
| 限定类型 | 2048 个不同基类型/限定符组合 | qualify_type |
| 结构/联合类型、枚举类型 | 分别 1024 个类型条目 | record_specifier、enum_specifier |
| 结构/联合成员记录 | 8191 个有效记录，共享成员池 | record_specifier |
| 结构/联合嵌套 | 超过 64 层拒绝 | record_specifier |
| 活动局部绑定 | 256 个，包含参数、typedef、局部 extern 等绑定 | local 及声明处理函数 |
| 固定栈帧 | 参数保存区、固定局部对象、运行时长度槽和临时区共用 65536 字节预算；局部对象按 8 字节边界计费，临时区另作对齐，frame_peak 记录最大活跃占用 | local、temporary、function |
| VLA 元素存储 | 运行时栈分配，按 16 字节对齐并逐页探测；每个局部 VLA 另占固定帧中 16 字节描述符及有关长度槽，元素不按固定帧的 65536 字节上限计费 | allocate_runtime_array、extent_slot、local |
| 可变修改类型的作用域记录 | 每函数最多 4095 条；仅原型处理不建立这些记录 | bind_variable_type |
| goto 记录 | 每函数最多 4096 条；标签确定后处理作用域检查和栈恢复 | record_vm_goto、resolve_vm_gotos |
| 静态数据区分配游标 | 不得超过 `0x2000000`；对齐和既有分配消耗预算 | allocate_global、static_declaration |
| 表达式、单目式、语句递归 | 各自超过 128 层拒绝 | expression、unary、statement |
| 整型/地址常量表达式递归 | 各自超过 128 层拒绝 | ce_unary、ce_inner、sc_unary、sc_expression |
| 初始化递归 | 超过 64 层拒绝；位字段额外花括号计入该限制 | initialize_object、initialize_bitfield |
| 初始化检查点 | 最多 128 个嵌套帧；额外帧还依赖堆分配成功 | initializer_checkpoint_push |
| 活动 switch case | 2048 个记录，嵌套 switch 共享当前池 | switch_label |
| 调用、对象引用、地址重定位记录 | 各自的前端记录池容量为 16384；目标文件合并后的重定位总数另不得超过 16384 | invoke、object_reference、地址引用入口、object-output.c |
| 字符串内容池 | 1048576 个内容单元，宽/窄字符串共享 | string_token |
| 生成映像/目标输出 | 映像游标不得达到 1049088；目标文件总大小不得超过 1049088，包含头和符号/重定位信息 | emit、object-output.c |
| 输入源码、预处理输出 | 各受 1048576 单元缓冲限制；预处理生成拼写另共用 1049088 单元空间 | main、pp_put、pp_generate |
| 宏名字 | 1024 个已建立条目；undef 不回收名字条目 | pp_define |
| 宏形参 | 最多 127 个普通形参；变参槽和调用参数还受专门检查 | pp_define、宏实参收集 |
| 宏定义 token 池 | 65536 项 | pp_save_token |
| 展开 token 节点 | 65535 个有效节点，释放后可复用 | pp_node |
| 隐藏集记录 | 131071 个有效条目，展开阶段重置/复用规则另行适用 | 隐藏集分配函数 |
| 宏展开递归、条件包含嵌套 | 各最多 128 层 | pp_expand_stream、pp_directive |
| 包含深度 | 根文件深度为 0；当前深度为 63 时拒绝再包含 | pp_load_header |
| 头文件路径 | 最多 1023 字节加终止符 | pp_header_char、pp_open_candidate |
| C1_INCLUDE 环境字符串 | 4096 字节缓冲；接口报告长度达到 4096 时拒绝 | pp_search_header |

“普通纯指针链”不等于所有混合派生声明器的总层数。数组、函数和限定类型会建立新的类型节点；它们同时受声明器节点数、递归深度和相应类型表容量限制。不能把 15 层解释成所有混合声明器的统一上限，也不能因解析递归上限为 64 就承诺 64 层连续指针。

初始化表达式写入目标后，若未创建需要保留到块结束的复合字面量，编译器恢复该表达式临时区的分配游标；最大帧占用仍保留。因此，一串初始化不会累计已失效临时对象的空间占用。复合字面量的存储按其生存期保留，不能借恢复游标提前复用。`complex/test-initializer-lifetime.ps1` 检查这一生存期与空间复用行为。

VLA 和可变修改类型是 C99 功能；上表给出它们对当前编译器共享资源的影响，不把它们当作 C89 必需语法。运行时栈容量由操作系统及映像配置共同限制；这些条目不保证任意动态数组大小均可分配。

`c89-supplemental-tests` 的 limits 组合测试使用两代编译器检查 C89 规定的最低组合能力，包括 511 个宏和文件对象、127 个局部名字/成员/枚举项、257 个 case、31 个函数/宏参数以及 8 层包含/条件嵌套。测试范围不包含上表所有极限，也不构成满足 C99 全部更高最低能力要求的证明。

这是编译器翻译资源表。独立链接器、操作系统可用内存、文件长度和进程栈等仍会施加额外限制；本表不将这些工具或环境的容量合并成一个虚假的统一最大程序大小。

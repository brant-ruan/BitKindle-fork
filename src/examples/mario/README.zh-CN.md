# Mario：第一关横向卷轴 GUI 示例

使用本项目自制 C 编译器、运行库和 PE 链接器构建的 Windows x64 平台游戏。以《超级马里奥兄弟》World 1-1 的地上路线为参照，包含 216 列关卡、横向镜头、砖块、问号块、金币、蘑菇变身、栗宝宝、乌龟及龟壳、管道、缺口、阶梯、旗杆和城堡。

角色、地形和背景由 C 代码与 GDI 绘制，文字使用系统字体，无须随附图片、ROM 或游戏引擎。本例为教学用途的玩法重现，布局、图形和物理并非原版逐像素复刻；不包含地下奖励房间、音效、火球及原版过关动画。到达旗杆即完成本关。

## 构建和运行

在发布包根目录的 **Windows PowerShell 5.1** 中执行。已有工具链时跳过第一步；`build-all.ps1 -All` 已编译本例，可直接运行。默认模式和 `-Full` 均不编译本例，构建模式见 [README.zh-CN.md](../../../README.zh-CN.md#构建模式)。

```powershell
# 尚未构建工具链时先执行；已有最终编译器和链接器可跳过。
& './build-all.ps1'
if (!$?) { throw '工具链构建失败' }

& './src/examples/mario/build.ps1'
if (!$?) { throw '游戏构建失败' }
& './src/examples/mario/build/mario.exe'
```

也可以直接双击生成的 `build/mario.exe`。只生成 Windows GUI 版本，启动时不附带控制台。窗口客户区为 960×544，界面文字为英文。

| 按键 | 操作 |
| --- | --- |
| 左右方向键 / A、D | 移动 |
| 空格 / 上方向键 / W | 跳跃；按住跳得更高，松开缩短跳跃 |
| Shift | 加速跑；可与移动、跳跃同时使用 |
| P | 暂停或继续 |
| R | 重新开始整局 |
| Esc / 关闭窗口 | 退出 |

正常游戏失去焦点时自动暂停，按 P 继续。初始 3 条命，每 100 枚金币增加一条命。蘑菇使角色长大并能顶碎砖块；大角色受伤后变小并短暂无敌，小角色受伤、掉坑或超时会损失一条命。

踩敌人可得分并反弹。乌龟被踩后缩壳，静止龟壳可踢动，移动龟壳可踩停，也会反弹、击倒敌人或伤害玩家。静止龟壳在玩家附近更新约 10 秒后恢复为乌龟。

越过第 104 列后设置复活点；尚有生命时，死亡后地形、敌人及计时重置，分数和金币保留。通关或生命耗尽后按 R 重开。

如使用自定义工具链或输出目录：

```powershell
& './src/examples/mario/build.ps1' `
    -BuildDirectory './work/walkthrough' `
    -OutputDirectory './work/mario'
if (!$?) { throw '游戏构建失败' }
& './work/mario/mario.exe'
```

`-BuildDirectory` 需要包含 `host/c1-stage2.exe` 和支持 `--subsystem windows` 的 `link-stage2.exe`。重建前请关闭同一路径下正在运行的游戏。

## 实现与构建来源

`mario.c` 包含正常游戏，`demo.h` 包含自动操作与完整场景演示测试。源码用 C99 模式编译，显式声明需要的 Windows x64 ABI，不依赖 Windows SDK、windows.h 或导入库。游戏逻辑使用 1/16 像素定点数和每秒 60 次固定更新；消息循环以 Win32 计时器驱动，短时延迟使用累积时间补帧。碰撞按像素小步处理，GDI 内存位图与 BitBlt 双缓冲绘图。

`build.ps1` 用自制编译器生成游戏目标文件与启用命令行参数的运行库目标文件，再以自制链接器链接，入口为 `__c1_start`，子系统为 `windows`。导入仅来自 Windows 的 KERNEL32、USER32 和 GDI32。PowerShell 只处理文本和工具调用，所有目标文件及 EXE 均由自制工具生成。

包装源码、目标文件及 EXE 默认保存在本例的 `build/`。根目录 `clean-all.ps1` 会整体删除该目录，包括测试报告；自定义 `-OutputDirectory` 须自行管理。

## 自动测试

```powershell
& './src/examples/mario/test.ps1'
# 自定义输出位置时：
# & './src/examples/mario/test.ps1' -Executable './work/mario/mario.exe'
```

先构建示例，再运行测试。脚本核对 PE 的 GUI 子系统字段，并依次运行同一 EXE 的三个模式，以退出码判定结果：前两项各超时 30 秒，演示测试超时 120 秒。根目录 `build-all.ps1` 的各模式均不运行这些测试。

- `--self-test`：检查 Win64 结构布局、移动与碰撞、道具、伤害、生命、计时、暂停、终点及龟壳行为；包含隔离敌人的按键驱动全关地形穿越。敌人交互另用独立场景测试。
- `--smoke-test`：创建隐藏窗口，检查按键、计时器、暂停与重开，通过 WM_PRINTCLIENT 绘制内存位图并核对像素。可额外传入 BMP 路径保存该帧，保存失败返回非零。

- `--demo-test`：无窗口运行自动玩家，保留全部敌人和道具，通过条件与下文可视演示相同。脚本传入 EXE 目录下的 `gameplay-test.txt` 作为报告路径；程序能打开该文件时记录进度和结果，报告写入失败不单独导致测试失败。

工具接口见 [USAGE.zh-CN.md](../../../USAGE.zh-CN.md)。

### 观看完整游戏场景演示

```powershell
& './src/examples/mario/build/mario.exe' --terrain-test-visible
```

窗口显示约 3 秒后，内置自动玩家开始操作。通过条件为：到达旗杆、顶至少两个奖励块、取得金币、收集场景金币、拾取蘑菇、踩栗宝宝、踩乌龟并踢壳。

自动玩家在复制的状态中试算后续输入，再将所选按键交给正常游戏更新；地图、敌人、计时、伤害和物理规则与手动游戏相同。路线试算可能降低绘制帧率。

界面显示交互计数及最终 PASS/FAIL；死亡、未满足条件通关或达到 6,000 次更新上限均判失败。演示模式失去焦点时不暂停，可按 P 暂停或继续、Esc 退出；结果画面保留，不自动关闭窗口。

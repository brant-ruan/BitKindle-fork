# 基础自举工具链

本目录包含 `seed.hex`、A0/A1/C0 的装配源码、基础 C1 的 C 源码，以及这一阶段的运行库和测试。

它的任务是从种子获得能编译后续工具的基础 C1。这里的编译器和头文件属于中间阶段，其能力和限制不代表最终的 `host/c1-stage2.exe`。用户程序应使用最终工具链，见 [使用手册](../../../USAGE.zh-CN.md)。

- [构建原理](../../../BOOTSTRAP.zh-CN.md)：解释 A0、A1、C0、桥接编译器与基础 C1 的关系。
- [逐阶段教程](../../../WALKTHROUGH.zh-CN.md)：提供 Seed 至 C1 的实际执行步骤。

本目录 `build.ps1` 组织基础构建，`build-c1.ps1` 构建桥接编译器并验证基础 C1 两代自编译，`audit.ps1` 检查该阶段产物。推荐通过发布根目录入口运行，以获得正确的路径和环境配置。

`SOURCES.json` 列出当前构建与测试输入。
